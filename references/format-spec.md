# 客户明细 Excel 格式规范（clientcard2excel）

本文件定义 `build_excel.py` 生成的 Excel 字段、分级、分类与视觉规范。AI 在填充
`LEADS` / `CONTACTS` 时应遵守本规范，确保多展会、多次产出风格一致、可比对。

---

## 1. 数据模型

### 1.1 LEADS（列表，每元素 8 字段，顺序固定）

```
(序号, 日期, 国家/地区, 渠道/客户类型, 意向品类, 意向强度, 备注, 后续动作)
```

| 索引 | 字段 | 类型 | 约定 |
|------|------|------|------|
| 0 | 序号 | str | `"1"`、`"16"`；与 CONTACTS 键关联；同展会连续 |
| 1 | 日期 | str | `YYYY-MM-DD`，展会接触日 |
| 2 | 国家/地区 | str | 国家 / 地区 / 城市，如「中国香港」「阿联酋（迪拜）」 |
| 3 | 渠道/客户类型 | str | 进口商 / 品牌 / 批发 / 零售 / 代理 / 贸易公司 … |
| 4 | 意向品类 | str | 客户关注的品类，如「AI毛绒玩具」「儿童相机」 |
| 5 | 意向强度 | str | 见 §2 分级 |
| 6 | 备注 | str | 关键对话、特殊诉求、关联信息、跨展复访标注 |
| 7 | 后续动作 | str | 下一步跟进建议 |

### 1.2 CONTACTS（字典，键=序号 str，值 6 字段，顺序固定）

```
{ "1": (联系人/职务, 公司名称, 电话, 邮箱, 微信, 地址) }
```

| 索引 | 字段 | 约定 |
|------|------|------|
| 0 | 联系人/职务 | 「姓名（职务）」，如「张三（采购经理）」 |
| 1 | 公司名称 | 全称 |
| 2 | 电话 | 含国家码，如 `+852 1234 5678` |
| 3 | 邮箱 | 公司邮箱优先 |
| 4 | 微信 | **微信号**（非昵称），可添加 ID |
| 5 | 地址 | 公司 / 办公地址 |

未拿到的字段填 `""`（空串），不要填 `"无"` 以免与真实空值混淆；合影类线索可填
`"仅合影待补充"`。

## 2. 意向强度分级与颜色

`classify_intent()` 把意向文本归一为下列 key，用于色块与排序：

| key | 触发词 | 背景色 | 含义 |
|-----|--------|--------|------|
| 已下单 | 含「已下单」 | `#C8E6C9` 绿 | 已成交 |
| 已购样品 | 含「样品」「已购」 | `#FFE0B2` 橙 | 已付钱买样 |
| 强 | 含「强」 | `#F8BBD0` 粉红 | 强意向 |
| 中 | 默认（不含上述） | `#FFF9C4` 浅黄 | 一般意向 |
| 低 | 含「低」 | `#ECEFF1` 灰 | 低意向 |

> 文本可带补充，如「强（意向很强）」「中（可能起量）」，归一只看触发词。
> 统计汇总按跟进优先级排序：已下单(5) > 强(4) > 已购样品(3) > 中(2) > 低(1)。

---

## 3. 地区分类（region_of）

用于「统计汇总」的地区分布。归类顺序：亚洲/中东 → 欧洲 → 美洲 → 非洲 → 大洋洲 → 其他。

- 含「待确认」或空 → `待确认`
- 「西班牙」+「语」→ `待确认`（西班牙语地区特判，避免误归欧洲）
- 含「香港/台湾/日本/韩国/泰国/印度/土耳其/阿联酋/迪拜/以色列…」→ `亚洲/中东`
- 含「俄罗斯/意大利/西班牙/捷克/挪威/克罗地亚/欧洲…」→ `欧洲`
- 含「美国/加拿大/墨西哥/巴西/阿根廷/巴拉圭…」→ `美洲`
- 含「南非/埃及/非洲…」→ `非洲`
- 含「澳大利亚/新西兰/澳洲…」→ `大洋洲`

如需新增国家关键词，直接扩展 `region_of()` 内对应列表即可。

## 4. Excel 视觉规范

| 项 | 规范 |
|----|------|
| 表头底色 | 品牌紫 `#6B4E9E` |
| 表头字体 | 微软雅黑 加粗 白色 11pt |
| 数据字体 | 微软雅黑 10pt |
| 边框 | 浅紫灰 `#D9D2E9` 细线 |
| 意向列 | 按 §2 色块填充 + 居中 |
| 冻结窗格 | `A2`（首行表头常驻） |
| 自动筛选 | 全表 `A1:N{行数}` |
| Sheet | 「客户明细」+「统计汇总」 |

### 4.1 「统计汇总」sheet 内容

1. 线索总数
2. 意向强度分布（带色块）
3. 地区分布（按大区计数）
4. 重点跟进排序：按 §2 优先级降序，列出 序号 / 国家地区 / 公司·联系人 / 微信 / 意向

## 6. 已知坑（写入脚本前务必确认）

1. **微信导出丢图**：zip 内 0 图或极少图常见，需用户重发；不要虚构照片内容。
2. **重复 append 翻倍**：每次重跑从 `LEADS` 全量重生成，切勿用 append 式脚本叠加运行。
3. **地区误分**：「西班牙语地区」特判已在 `region_of` 处理；新增地区关键词时注意顺序。
4. **微信号 vs 昵称**：资料页的微信号才是可添加 ID，昵称不可直接搜。
5. **跨展复访**：同一客户跨展会出现时，用备注关联（如「= 香港展 #38」），不重复占序号。
